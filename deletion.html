Suppression du compte et des données – Pedia'Respi

Cette page explique comment les utilisateurs de Pedia'Respi peuvent supprimer leur compte et les données associées, ou supprimer leurs données de santé et de suivi sans supprimer leur compte.

1. Supprimer définitivement son compte Pedia'Respi

La suppression du compte peut être effectuée directement depuis l'application Pedia'Respi.

  1. Ouvrez Pedia'Respi et connectez-vous à votre compte.
  2. Ouvrez les paramètres de l'application.
  3. Accédez à la section relative au compte.
  4. Sélectionnez « Supprimer mon compte ».
  5. Confirmez la suppression selon les instructions affichées.
Attention : la suppression du compte est définitive.

La suppression du compte entraîne la suppression des données associées au compte Pedia'Respi, notamment les données de profil, de suivi, les événements, routines, informations de calendrier et documents associés au compte.

Certaines copies techniques temporaires ou sauvegardes peuvent subsister pendant une durée limitée avant leur suppression ou leur expiration, conformément au fonctionnement des prestataires techniques utilisés.

2. Supprimer les données de santé sans supprimer le compte

Pedia'Respi permet également de retirer le consentement au traitement des données de santé sans supprimer le compte d'authentification.

  1. Ouvrez Pedia'Respi et connectez-vous à votre compte.
  2. Ouvrez les paramètres de l'application.
  3. Accédez à « Confidentialité et données ».
  4. Sélectionnez l'option permettant de retirer votre consentement.
  5. Confirmez l'opération selon les instructions affichées.

Cette opération supprime les données de santé et de suivi associées au compte, notamment les données de profil de suivi, journal, routines, calendrier et documents concernés.

Le compte d'authentification est conservé. Si l'utilisateur souhaite ensuite réutiliser les fonctionnalités nécessitant le traitement de données de santé, un nouveau consentement lui sera demandé.

3. Demander une suppression sans accès à l'application

Si vous ne pouvez pas accéder à l'application ou à votre compte, vous pouvez demander la suppression de votre compte ou de vos données en contactant Pedia'Respi à :

pediarespi.contact@gmail.com

Afin de protéger les données contre les demandes frauduleuses, une vérification permettant de confirmer que la demande concerne bien le titulaire du compte pourra être nécessaire avant la suppression.

4. Données concernées

Selon les fonctionnalités utilisées, les données supprimées peuvent notamment comprendre :

  • les informations de profil ;
  • les informations de suivi respiratoire ;
  • les événements et observations enregistrés ;
  • les routines et leur suivi ;
  • les informations de calendrier ;
  • les documents associés au compte ;
  • les autres données de suivi enregistrées dans Pedia'Respi.
